Mot de passe oublié

Un mot de passe ne peut pas être changé depuis une page web : on supprime le compte, le joueur recrée son profil avec le même pseudo, puis on lui rend sa progression.

  1. Dans la console Firebase, Authentication → Users, cherche , puis ⋮ → Supprimer le compte.
  2. (supprime la réservation et l'ancienne ligne des records ; la progression est gardée de côté)
  3. Le joueur fait Créer mon profil avec le même pseudo et un nouveau mot de passe.
  4. (à faire après l'étape 3 : il la retrouve à sa prochaine ouverture du jeu)
